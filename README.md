# "NexusFlow": Visual IoT Telemetry & Rule Engine

NexusFlow is a MERN-based IoT telemetry and rule-engine platform designed to collect, process, visualize, and monitor real-time sensor data from IoT devices.
The project aims to provide a visual workflow-based approach for creating IoT processing rules, reducing the need for hardcoded device logic.

## ✨ Features

### Currently Implemented

- 📡 IoT telemetry data ingestion
- 🔌 REST API using Node.js and Express.js
- 💾 MongoDB Atlas database integration
- 📋 Telemetry data model using Mongoose
- 🌡️ Temperature, pressure, and vibration data storage
- ❤️ Backend health-check API
- 🔐 Environment-based database configuration
- 🧪 API testing using PowerShell/REST requests

### Planned Features

- 🎨 Visual drag-and-drop workflow builder
- ⚙️ Dynamic rule engine
- 🔀 Node-based IoT processing pipelines
- 🚨 Automated alerts
- 📊 Real-time monitoring dashboard
- 📈 Telemetry visualization
- 🔄 Real-time workflow execution
- 👥 Device management
- 🔐 Authentication and role-based access control
